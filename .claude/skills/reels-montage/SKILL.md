# Монтаж рилс

Сначала прочитай `montage/STYLE.md` — там все утверждённые правила (шрифты, цвета, раскладка, что нельзя). Затем `montage/README.md` — как устроен конвейер.

## Порядок работы
1. **Входные файлы.** Исходник, сценарий (текст), референсы, материалы. Всё рабочее — в папке `work/` (она в .gitignore, репозиторий публичный): `work/input/`, `work/fonts/`, `work/sfx/`, `work/img/`. Шрифты и звуки заказчика никогда не коммитить. Если нет `fonts/BebasNeueBold.otf` или `sfx/apple.mp3` — попроси заказчика прислать.
2. **Разбор.** Раскадровка исходника и референсов (`ffmpeg ... tile`), найди паузы, план по смыслам: где хук, где графика, где материалы.
3. **Тайминг слов.** из папки `work/`: `python ../montage/tools/align.py --text script.txt --audio input/source.mov --out words.json`. Проверь концы предложений; спорные места — якоря `--anchors`.
4. **Рендер.** Возьми за основу пример: `montage/examples/tenge/` (экран поделён + карточки + материалы) или `montage/examples/ai_creator/` (титры над головой, хук с силуэтом). Меняй список `card(...)` (титры) и `PANELS` (графика/материалы). Сначала превью кадров: `PREVIEW="1.0,5.0,..." python render.py`, потом полный рендер.
5. **Звук.** `python ../montage/tools/mix.py ...` по правилам из STYLE.md, затем склейка ffmpeg.
6. **Проверка.** Раскадровка готового ролика, титры не на лице, буквы на месте.
7. **Работай до конца без вопросов**, если всё есть: босс обычно не смотрит в процессе. Спорные решения принимай сам по STYLE.md и перечисли их в отчёте. Останавливайся и спрашивай только если нет исходника, сценария, шрифта или звука.
8. **Отчёт боссу** (последнее сообщение, файл ролика прикрепить):
   ```
   Босс, монтаж готов ✅  <название ролика>
   Сделал:
   - титры: ... / графика: ... / материалы: ... / звук: ...
   Проверь, пожалуйста:
   - <таймкоды мест, где я не уверен: факты, имена, громкость>
   Нужно от тебя:
   - <материалы или решения, если чего-то не хватило>
   ```
9. Добавь строку в `plan/log.md` (дата — Монтажёр — что сделано — «ждёт проверки») и закоммить её.

## Правки заказчика
Каждую новую утверждённую правку стиля добавляй в `montage/STYLE.md`, чтобы следующие ролики сразу были в нужном стиле.
