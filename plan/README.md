# Система «12 недель» и сотрудники-ассистенты

## Файлы
- `goals.md` — цели года и 12 недель (заполняет босс один раз, правит по необходимости).
- `weeks/week-NN.md` — план и итоги каждой недели: задачи, ответственный «сотрудник», статус.
- `log.md` — короткий журнал: что сделано ассистентами (монтаж, сценарии, анализ).

## Сотрудники (роли Claude Code)
| роль | что делает | как запускать |
| --- | --- | --- |
| Монтажёр | монтирует рилс в стиле `montage/STYLE.md`, в конце пишет отчёт «Босс, монтаж готов…» | новая сессия: исходник + сценарий + шрифты + звук, «смонтируй» |
| Сценарист-аналитик | хуки и сценарии рилс, анализ аккаунтов и трендов в Instagram | новая сессия: «напиши 3 сценария про …» / «разбери аккаунт …» |
| Планировщик | понедельник — план недели из целей; пятница — итоги и процент выполнения | автоматически по расписанию, присылает уведомление |

## Статусы задач
`[ ]` не начато · `[~]` в работе · `[?]` ждёт проверки босса · `[x]` готово

## Формат отчёта боссу (для всех ролей)
```
Босс, <что> готово ✅
Сделал:
- ...
Нужно от тебя:
- проверить: <что именно и где>
- решить: <вопрос, если есть>
Дальше по плану: <следующая задача>
```
