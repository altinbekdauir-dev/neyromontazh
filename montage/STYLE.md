# Паспорт стиля рилс (утверждено заказчиком)

Всё ниже согласовано по правкам на реальных роликах. Не меняй без запроса.

## Формат
- Вертикаль 1080×1920, 30 fps, H.264 (CRF 19), звук AAC 256k.
- Язык титров — казахский. Перед рендером проверь, что в шрифте есть все буквы: ә ғ қ ң ө ұ ү һ і.

## Шрифты
- **Крупные слова (заголовок):** Bebas Neue Bold (`fonts/BebasNeueBold.otf`, файл заказчика, в репозиторий не класть).
- **Мелкие слова сверху/снизу:** Montserrat SemiBold, строчные.
- **Курсив-акцент (иногда):** Good Vibes Pro (`fonts/GoodVibesPro.ttf`, файл заказчика). Только строчными. В нём нет ә ғ қ ң ө ұ ү — такие слова набирать Bebas. «і» и «һ» можно заменить латинскими i/h.
- Обычный Bebas Neue из Google Fonts без кириллицы — не подходит.

## Цвета
- Текст белый, мягкая тень.
- Акцент — бежевый **RGB 236,196,146** (как «ТАППАЙТЫН» на одобренном скрине).
- Новое слово появляется бежевым и через ~0,25 с становится белым. Главные слова остаются бежевыми.
- **Нельзя:** золотой градиент, синий неон. Свечение — только тёплое и только вокруг букв (без квадратного фона).

## Раскладка титров (как в референсе «Claude умеет»)
- Блок из 2–3 строк: сверху мелкие слова с широкими пробелами → по центру крупный заголовок на всю ширину → снизу мелкая строка.
- Межстрочный интервал маленький (≈12 px между буквами строк).
- Позиция чередуется: **сверху слева → по центру → снизу справа** (не всё по центру).
- Текст **никогда не на голове и не на лице**. Над головой — только с отступом; если места мало — на уровне груди.
- В режиме «экран поделён» (эксперт сверху, графика снизу) титры стоят на уровне груди и чередуют выравнивание: слева / центр / справа.

## Анимации
- Появление: размытие → резкость на месте (как в референсе), без бегущей строки слева направо.
- Уходы (по ситуации): размытие, рассыпание в пыль (для «денег нет», «исчезло»), складывание, смаз.
- Буквы падают по одной — для 1–2 главных слов за ролик.
- **Нельзя:** пульсирующий зум (punch-in) — заказчик просил убрать.
- Хук: если в исходнике уже есть эффект (например, белый силуэт-флешбэк) — оставить как в исходнике.

## Графика и материалы (формат «экран поделён», референс 2)
- Эксперт сверху (строки 250–1250 исходника), снизу панель 1080×920: светлая клетчатая бумага + карточка с наклоном ±3°, тень, появление снизу.
- Свои карточки: карта с маршрутом и счётчиком, год с зачёркиванием, счётчики, календарь, кнопка «ЖАЗЫЛЫҢЫЗ».
- Фото/видео материалов — в карточке с белой рамкой; можно подпись Bebas + красная подпись Montserrat.
- Подписывать людей по имени только если заказчик сам сказал, кто на фото.
- Чеки и скриншоты: личные данные (имена, телефоны, номера квитанций) — размыть, суммы оставить. Никогда не рисовать чеки самому.

## Звук
- Только заказчика звук (`sfx/apple.mp3` = Apple_2, удар через 0,385 с от начала файла).
- Звук **только** на: словах хука, акцентных (бежевых) словах, появлении карточек. На обычный текст — без звука. Музыку не добавлять, если не просили.
- Громкость: на 30% тише голоса (70% от громкости речи). Звуки на чеках/скриншотах — тише (≈40%). Лимитер сверху.

## Перед отправкой
- Раскадровка всего ролика (ffmpeg tile) — проверить, что титры не на лице, нет обрезанных слов, все казахские буквы на месте.
- Сверить факты сценария с источниками и сказать заказчику, если что-то спорное.
